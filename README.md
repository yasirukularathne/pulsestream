# PulseStream

Real-Time Hospital Patient Monitoring & Data Reconciliation Platform

## Course

EC8203 Applied Big Data Engineering Mini-Project

## Architecture

Lambda Architecture

## Purpose

PulseStream monitors synthetic hospital patient vital-sign data in real time
and reconciles daily laboratory results to generate operational risk flags.

## Data Sources

- Real-time synthetic patient vitals
- Daily synthetic laboratory CSV files

## Technology Stack

- Python
- Apache Kafka
- Apache Spark Structured Streaming
- Apache Airflow
- PostgreSQL
- FastAPI
- Streamlit
- Docker

## Risk Levels

- normal
- watch
- elevated

> This system is for operational risk flagging only.
> It is not a clinical decision-support or diagnostic system.
